# Wayfinder — geography practice

An offline geography game: capitals, flags, borders, map modes, rivers & mountains, Border Chain, Mystery Country, Higher or Lower, Flag Builder, achievements and more — for all 197 countries.

**Play:** open the GitHub Pages link for this repository. On a phone, add it to your home screen (iPhone: Safari → Share → *Add to Home Screen*; Android: Chrome → ⋮ → *Install app*) and it works offline.

**On a Mac without internet:** download the repository and double-click `index.html`, or use `Start Wayfinder.command` to install it as an app.

Map data: Natural Earth via world-atlas (public domain). Flags: flag-icons (MIT). Country facts: world-countries (ODbL). Fonts: Inter & Fraunces (OFL).
