      Install as an app

      Works on iPhone, iPad, Android, Windows, Mac and Chromebook. Once installed it opens like a normal app and works offline.

      1. Start the launcher. In the Wayfinder folder, double-click Start Wayfinder.command. The first time, macOS may ask — right-click it, choose Open, then Open again. Wayfinder opens in your browser.
      2. Install it. In Chrome: click the install icon at the right of the address bar (or menu ⋮ → Cast, save and share → Install page as app). In Safari: File → Add to Dock.
      3. Play from your Dock or Launchpad. After installing it works offline — you don’t need the launcher any more.

      Progress in the installed app is separate from the browser version. Use Save a backup file here and Load a backup file in the app to bring it across.
